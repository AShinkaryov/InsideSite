Почему Stream не загружает весь файл в память сразу?

Потому что он читает и передает данные маленькими порциями (chunki), обрабатывая их поочередно, а не пытаясь вместить весь файл целиком в RAM[cite: 10].

Что такое chunk (чанк)?

Это небольшой буфер (кусок данных фиксированного размера), передаваемый по цепочке потоков.

Как связаны Readable, Transform и Writable?

Readable порождает данные (источник), Transform принимает их, изменяет «на лету», а Writable принимает и записывает/выводит результат. Метод pipe() связывает их воедино, автоматически управляя скоростью передачи потока (backpressure)[cite: 10].
